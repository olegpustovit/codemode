What changed in v7

Reserve room for each source

The 3,072-byte manifest reserves ranked names before upgrading them to signatures across sources. Long signatures can fall back to complete names.

Find status tools by partial name

Search accepts identifier prefixes and ranks matches for nudge list_statuses. If the query finds nothing, separately labeled suggestions can recover a near miss within the caller’s workspace.

Expose reply shape earlier

Long raw prints can include a compact field outline. Generic tool replies can also teach future searches and descriptions a bounded field/type outline. Run classification counts probe patterns and cannot establish which execution saw a learned hint.

The live manifest fits in 2,959 bytes and includes list_issue_statuses and create_issue. Both status queries found the intended tool at rank one. Static literal tools.search calls in scored standard traces fell from 182 to 50. The live Artifacts print exposed learned shape support. Scored v7 traces contain 15 explicit print-shape hints. These runs measure the combined change.
