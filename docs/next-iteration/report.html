What shipped in the gateway

Signatures in one place

The execute description carries up to 3,072 bytes of scoped signatures and declared output keys. E2 favored the description over initialize instructions. Listed tools can be called directly in a single script.

Structural feedback

Brief search results show bounded return skeletons. Python key, type and index errors can include the last upstream reply’s shape. The projection example shows _fields. Unknown schema keys stay unknown until a live reply provides evidence.

Evidence and limits

Each current arm warmed its prefix once, then ran as a block. Warm-up outcomes are preserved separately. The standard and heavy runs used Codex CLI 0.169.0 with gpt-6.1-sol. The Codemode arm applies the qualified deferral-off profile.

Input after request one is total input less cache reads after removing the first request. It reconciles against run totals for 120 of 120 v6 runs. A probe classification is a code-shape heuristic, including direct prints that may have been useful final work.

The median share of input served by cache rose from 73.2% in E5 to 78.2% in v6. Older client, prompt, cache and concurrency settings differ across releases. Historical differences are descriptive. The user paused Claude evaluation after the compatibility probe, so v6 does not have a Claude qualification cohort.

Live build 4845aabf3bcc passed the deployment gate and all eight smoke runs. The restored backup preserved 28 tables. The hardened ARM suite passed 155 checks and its long tier passed 163. Browser functional workflows passed after isolating the pane timing assertion. Pane p95 was 56.8 ms against 50 ms.
